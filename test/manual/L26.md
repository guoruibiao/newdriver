# L26 · 网格线区域禁停

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 任何车道 + 绿灯 + 拥堵车辆在场 + Space 停车等待 → 正确
- 等拥堵消除后 + 任何方向通行 → 100 分
- 任何车道 + 无拥堵 + 通行 → 100 分

## 失败路径
- 任何车道 + 拥堵在场 + 直行/左转/右转/掉头 → 网格线违章 → 扣 30
- 任何车道 + 红灯 + 直行/左转 → 扣 30

## 边界
- 绿灯 + 拥堵消除后 → gridLineBlock 返回 correct=true
- 直行车道 + 按 ← → wrong-lane-for-action → 扣 30
