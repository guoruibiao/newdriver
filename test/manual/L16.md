# L16 · 可变车道

## 随机出发
- 车辆随机出现在左转/可变/右转车道之一

## 通关路径
- 可变车道出发 → 观察 LED 指示器方向 → LED=直行按 ↑ 或 LED=左转按 ← → 100 分
- 左转车道出发 → 绿灯按 ← 左转 → 100 分
- 右转车道出发 → 红灯按 → 右转 → 100 分（圆饼不禁右）

## 失败路径
- 可变车道 + LED=直行 + 按 ← 左转 → 方向不匹配 → 扣 30
- 可变车道 + LED=左转 + 按 ↑ 直行 → 方向不匹配 → 扣 30
- 可变车道 + 红灯 + LED=直行按 ↑ → 红灯 → 扣 30

## 边界
- 左转车道 + 红灯按 ← → 扣 30（非可变车道走普通信号规则）
- 右转车道 → circleRightBySignal → 任何灯态右转正确
