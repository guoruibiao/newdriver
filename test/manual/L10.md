# L10 · 多车道+箭头灯：双重校验

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 变道到与箭头灯匹配的车道 → 通行
- 例：直行车道出发 + forward-green → 按 ↑ 直行 → 100 分
- 例：直行车道出发 + left-green → 按 A 变到左转车道 → 按 ← 左转 → 100 分

## 失败路径
- 左转车道 + left-green 之外按 ← → 箭头红 → 扣 30
- 直行车道 + forward-green 之外按 ↑ → 箭头红 → 扣 30
- 车道不匹配（直行车道按 ←）→ wrong-lane-for-action → 扣 30

## 边界
- 任何车道 + Space 停车 → 正确
- all-red 时任何通行动作 → 扣 30
