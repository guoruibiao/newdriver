# L22 · 避让行人

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 任何车道 + 绿灯 + 行人在场 + Space 停车让行 → 正确
- 等行人通过后 + 任何方向通行 → 100 分
- 任何车道 + 无行人 + 通行 → 100 分

## 失败路径
- 任何车道 + 绿灯 + 行人在场 + 直行/左转/右转/掉头 → 未避让行人 → 扣 30
- 任何车道 + 红灯 + 直行/左转 → 扣 30

## 边界
- 行人通过后自动消失 → anyPedestrianInOrApproachingZone=false
- 直行车道 + 按 ← → wrong-lane-for-action → 扣 30
