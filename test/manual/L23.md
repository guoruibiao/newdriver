# L23 · 圆饼红+左转绿箭头

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 左转车道 + 圆饼红+左转绿箭头 + 按 ← 左转 → 100 分
- 直行车道 + 圆饼绿 + 按 ↑ 直行 → 100 分
- 右转车道 + 圆饼红 + 按 → 右转 → 100 分（圆饼不禁右）

## 失败路径
- 直行车道 + 圆饼红+左转绿 + 按 ↑ 直行 → 扣 30
- 左转车道 + 圆饼红+箭头全红 + 按 ← 左转 → 扣 30
- 任何车道 + 圆饼红 + 按 ↑ 直行 → 扣 30

## 边界
- 左转车道 + 按 ↑ → wrong-lane-for-action → 扣 30
- 右转车道 + 按 ← → wrong-lane-for-action → 扣 30
