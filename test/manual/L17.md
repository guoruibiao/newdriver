# L17 · 铁道路口

## 通关路径
- dp-railroad: 栏杆放下 + Space 停车 → 正确
- 栏杆抬起 + 按 ↑ 直行通过铁路 → 正确
- dp-intersection: 绿灯 + 按 ↑ 直行 → 100 分

## 失败路径
- dp-railroad: 栏杆放下 + 按 ↑ 直行 → 闯越铁路 → 扣 50
- dp-intersection: 红灯 + 按 ↑ 直行 → 闯红灯 → 扣 30
- dp-intersection: 红灯 + 按 ← 左转 → 闯红灯 → 扣 30

## 边界
- dp-intersection: 红灯 + 按 → 右转 → 正确（圆饼不禁右）
- dp-railroad: 栏杆抬起 + Space 停车 → 正确（安全停车）
