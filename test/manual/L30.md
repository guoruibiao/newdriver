# L30 · 禁止左转标志

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 直行车道 + 绿灯 + 按 ↑ 直行 → 100 分
- 右转车道 + 按 → 右转 → 100 分（圆饼不禁右）
- 任何车道 + Space 停车 → 正确

## 失败路径
- 左转车道 + 绿灯 + 按 ← 左转 → 违反禁止左转标志 → 扣 30
- 左转车道 + 绿灯 + 按 U 掉头 → 违反禁止左转标志 → 扣 30
- 任何车道 + 红灯 + 直行 → 扣 30

## 边界
- 禁止左转标志任何灯态下生效
- 直行车道 + 按 ← → wrong-lane-for-action → 扣 30
- 右转车道 + 红灯 + 按 → 右转 → 正确（圆饼不禁右）
