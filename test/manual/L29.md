# L29 · 红灯闪烁

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 任何车道 + 红灯闪烁 + Space 停车 → dp-flash-stop 解决
- 按 ↑/←/→ 通行 → 100 分
- 右转车道 + 红灯闪烁 + 按 → 右转 → 100 分（圆饼不禁右）
- 绿灯 + 通行 → 100 分

## 失败路径
- 任何车道 + 红灯闪烁 + 直行/左转（未先停车）→ 扣 30
- 绿灯闪烁期间直行/左转 → 扣 30

## 边界
- 停车后 dp-proceed 触发 → 可自由选择方向
- 红灯闪烁 + 右转 → 圆饼不禁右 → 正确
- 直行车道 + 按 ← → wrong-lane-for-action → 扣 30
