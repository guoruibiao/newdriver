# L15 · 信号灯故障

## 通关路径
- dp-slow: 信号灯全灭 + Space 停车观察 → 正确
- dp-proceed: 已减速 + 按 ↑ 直行 → 正确 → 100 分
- dp-slow: 信号恢复绿 + 按 ↑ 直行 → 正确

## 失败路径
- dp-slow: 信号全灭 + 按 ↑ 直行（未减速）→ 扣 30
- dp-slow: 信号全灭 + 按 ← 左转（未减速）→ 扣 30
- dp-proceed: 灯恢复红 + 按 ↑ 直行 → 扣 30

## 边界
- dp-slow: 信号全灭 + 按 → 右转 → 正确（圆饼不禁右）
- dp-proceed: 缺少 prompt 字段已修复
