# L21 · 让右方来车先行

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一
- 无信号灯

## 通关路径
- 任何车道 + NPC在场 + Space 停车让行 → 正确
- 等NPC通过后 + 任何方向通行 → 100 分
- 任何车道 + 无NPC + 通行 → 100 分

## 失败路径
- 任何车道 + NPC在场 + 按 ↑/←/→ 通行 → 未让右方来车 → 扣 30
- 任何车道 + NPC在场 + 按 U 掉头 → 未让右方来车 → 扣 30

## 边界
- NPC 通过后自动消失 → 下一帧 anyNPCInOrApproachingZone=false
- 直行车道 + 按 ← → wrong-lane-for-action → 扣 30
