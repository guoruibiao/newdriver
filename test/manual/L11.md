# L11 · 转弯等待区

## 随机出发
- 随机生成左转或右转等待区
- 车辆随机出现在两个车道之一

## 通关路径（出发在转弯车道）
- dp-enter: 直行绿灯 + 按 ← 或 → 进入等待区
- 等待区停车 → 箭头绿灯亮 → 按 ← 或 → 完成转弯 → 100 分

## 通关路径（出发在直行车道）
- dp-enter: 绿灯 + 按 ↑ 直行通过 → 100 分（dp-turn 自动解决）

## 失败路径
- dp-enter: 直行红灯 + 按 ← 进入待转区 → 闯红灯 → 扣 30
- 等待区内箭头仍红 + 按 ← 转弯 → 提前转弯 → 扣 30
- 直行车道 + 按 ←（车道不匹配）→ wrong-lane-for-action → 扣 30
