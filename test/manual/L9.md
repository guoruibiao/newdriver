# L9 · 多车道：正确车道通行

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 按 A/D 变道到正确车道 → 信号灯匹配时通行
- 例：左转车道出发 → 按 D 变到直行车道 → 绿灯按 ↑ 直行 → 100 分

## 失败路径
- 左转车道 + 按 ↑ 直行 → wrong-lane-for-action → 扣 30
- 直行车道 + 红灯按 ↑ → 闯红灯 → 扣 30
- 右转车道 + 按 ↑ 直行 → wrong-lane-for-action → 扣 30

## 边界
- 右转车道 + 红灯按 → 右转 → 正确（圆饼不禁右）
- 左转车道 + 绿灯按 ← 左转 → 正确
- 任何车道 + Space 停车 → 正确
