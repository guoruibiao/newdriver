# L24 · 避让特种车辆

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 任何车道 + 救护车在场 + Space 停车让行 → 正确
- 等救护车通过后 + 任何方向通行 → 100 分
- 任何车道 + 无救护车 + 通行 → 100 分

## 失败路径
- 任何车道 + 救护车在场 + 直行/左转/右转/掉头 → 未避让特种车辆 → 扣 30

## 边界
- 救护车通过后自动消失 → anyEmergencyVehicleApproaching=false
- 直行车道 + 按 ← → wrong-lane-for-action → 扣 30
