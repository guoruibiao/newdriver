# L20 · 右转让左转

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 右转车道 + 绿灯 + NPC在场 + Space 停车让行 → 正确
- 等NPC通过后 + 按 → 右转 → 100 分
- 左转车道 + 绿灯 + 按 ← 左转 → 100 分（左转不受右转让左转规则约束）
- 直行车道 + 绿灯 + 按 ↑ 直行 → 100 分

## 失败路径
- 右转车道 + 绿灯 + NPC在场 + 按 → 右转 → 未让左转 → 扣 30
- 任何车道 + 红灯 + 直行/左转 → 扣 30

## 边界
- 右转车道 + 绿灯 + 无NPC + 按 → 右转 → 正确
- u-turn: 左转车道 + 绿灯 + uTurnBySignal 判定
