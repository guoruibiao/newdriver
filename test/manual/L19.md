# L19 · 转弯让直行

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一

## 通关路径
- 左转车道 + 绿灯 + NPC在场 + Space 停车让行 → 正确
- 等NPC通过后 + 按 ← 左转 → 100 分
- 直行车道 + 绿灯 + 按 ↑ 直行 → 100 分
- 右转车道 + 按 → 右转 → 100 分（圆饼不禁右）

## 失败路径
- 左转车道 + 绿灯 + NPC在场 + 按 ← 左转 → 未让直行 → 扣 30
- 任何车道 + 红灯 + 直行/左转 → 扣 30

## 边界
- 左转车道 + 绿灯 + 无NPC + 按 ← 左转 → 正确（无对向来车）
- 直行车道 + 按 ← 左转 → wrong-lane-for-action → 扣 30
- u-turn: 左转车道 + 绿灯 + NPC在场 → 扣 30
