# L18 · 压线违章

## 随机出发
- 车辆随机出现在左转/直行/右转车道之一
- 实线（x=390, x=450）阻止变道 → 被困在当前车道

## 通关路径
- 直行车道出发 + 绿灯按 ↑ 直行 → 100 分
- 左转车道出发 + 绿灯按 ← 左转 → 100 分
- 右转车道出发 + 红灯按 → 右转 → 100 分
- 任何车道 + Space 停车 → 100 分

## 失败路径
- 任何车道 + 红灯按 ↑ 直行 → 扣 30
- 尝试变道（A/D）→ 被实线阻止，无变化

## 边界
- _continuousEval: 实时检查压线/导流线违章（保持车道即不触发）
