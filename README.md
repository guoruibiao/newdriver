# 新手司机 · 道路规则考核游戏

俯视角 2D 驾驶规则教学游戏，覆盖中国交通法规核心场景。30 关递进式教学，从红绿灯基础到复杂路口综合考核。

单 HTML 文件架构，零依赖，浏览器直接运行。

## 运行

```bash
# 方式 1：直接双击 index.html
# 方式 2：起本地 server（推荐，避免 file:// 限制）
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 操作

| 按键 | 功能 |
|------|------|
| Space | 停车 / 继续行驶 |
| ↑ | 直行通过路口 |
| ← | 左转 |
| → | 右转 |
| U | 掉头 |
| A / D | 向左 / 向右变道 |
| Esc | 暂停 |

移动端自动显示底部虚拟按钮。限速关卡中 ↑/↓ 用于加速/减速。

## 游戏机制

- **随机出发**：多车道关卡车辆随机出现在左转/直行/右转车道之一，必须在本车道执行对应操作
- **车道门控**：左转车道只能左转，直行车道只能直行，右转车道只能右转，掉头必须在左转车道
- **圆饼不禁右**：圆饼红灯时允许右转（除非有禁右标志或箭头红灯）
- **让行优先**：转弯让直行、右转让左转、让右方来车先行、避让行人/特种车辆
- **标志优先**：禁止左转/掉头标志在任何灯态下生效；让行/停车标志无信号灯时按标志规则判定
- **连续评估**：压线/导流线违章、限速等场景实时检测，不只是决策点判定
- **进度持久化**：通关进度保存在 localStorage，刷新页面不丢失

## 测试

### 自动判分

打开浏览器 console，复制 `test/console-snippet.js` 全部内容粘贴运行。覆盖 L1-L30 全部关卡的决策评估逻辑。

### 手动测试卡

每关一份 `test/manual/L{n}.md`，列出通关路径、失败路径、边界条件，用于浏览器实际操作验证。
